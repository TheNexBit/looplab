# Code of Conduct

Looplab is made by musicians for musicians, of every level and background. We want this project to
be a friendly place to learn and build together.

## Expected behaviour

- Be kind and patient, especially with beginners and with people writing in a second language.
- Give feedback on the work, not on the person, and assume good intentions.
- Accept that decisions are sometimes different from the one you proposed.

## Not acceptable

- Insults, harassment, discrimination or sexualised language and images.
- Personal attacks, trolling, or publishing someone's private information.
- Any behaviour that would be inappropriate in a rehearsal room shared with strangers.

## Enforcement

Report a problem by contacting the maintainer, TheNexBit, through GitHub. Reports are handled
privately. Comments, commits, issues and other contributions that break this code may be edited or
removed, and repeated or serious cases can lead to a ban from the project.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
